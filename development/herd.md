# Laravel Herd

The root-level `herd.yml` provides a shared local Herd configuration for this
project:

- site: `https://laravel-native-boilerplate.test`
- PHP: 8.5
- TLS: enabled with a locally trusted certificate
- services: none; the default application configuration uses SQLite

Herd Pro is not required for this configuration because it does not provision
any services.

## First-time setup

Install and start [Laravel Herd](https://herd.laravel.com), then run these
commands from the project root:

```bash
cp .env.example .env
herd link laravel-native-boilerplate --secure --isolate=8.5 --update-env
herd init
herd composer run setup
```

The explicit `herd link` command is required because this repository may be
cloned outside one of Herd's parked paths. It registers the site, creates its
trusted certificate, selects PHP 8.5, and updates `APP_URL` in the local
`.env`. `herd init` then applies the committed manifest and any future shared
configuration.

After setup, the local `.env` should contain the following value so URLs
generated by Laravel use the Herd domain:

```dotenv
APP_URL=https://laravel-native-boilerplate.test
```

Do not commit `.env`.

## Daily use

Herd serves Laravel continuously, so only Vite needs to run for frontend hot
module replacement:

```bash
npm run dev
```

Open the application with:

```bash
herd open
```

Run PHP and Composer commands through Herd so they use the PHP version pinned
for the site:

```bash
herd php artisan test
herd composer test
```

Start a queue worker separately when the feature under development dispatches
queued jobs:

```bash
herd php artisan queue:listen --tries=1
```

## Applying configuration changes

After pulling a change to `herd.yml`, reapply it with:

```bash
herd init
```

This applies additions and updates without removing unrelated existing Herd
configuration. Do not run `herd init --fresh` unless deliberately replacing
the manifest through Herd's interactive wizard.

## Troubleshooting

Confirm which PHP executable and site driver Herd selected:

```bash
herd which-php
herd which
```

If the local site or certificate is stale, reapply the manifest and restart
Herd:

```bash
herd link laravel-native-boilerplate --secure --isolate=8.5 --update-env
herd init
herd restart
```

The Herd manifest does not manage Node.js. Use a Node.js release supported by
the versions of Vite and other packages declared in `package.json`.
